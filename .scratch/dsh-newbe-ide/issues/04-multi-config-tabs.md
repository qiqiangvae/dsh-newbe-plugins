# 04: 一个项目多条启动配置：两层 tab

**What to build:** 一个项目 tab 下面挂多个启动配置 sub tab（如 `web`、`worker`），每条各自独立启停、独立日志、独立环境变量，互不影响；一级 tab 显示条数角标与聚合状态点。

**Blocked by:** 02 (一条启动配置能一键启停，日志实时滚出来)

**Status:** ready-for-agent

- [ ] 项目 tab 下渲染多个启动配置 sub tab，选中态清晰，二级 tab 独立一行
- [ ] 同一项目的两条启动配置可同时运行，各自日志互不串台；停掉一条不影响另一条
- [ ] 一级 tab 显示启动配置条数角标，状态点为聚合（任一条在跑 = 运行中）
- [ ] 二级 tab 可新增、可删除（删除不影响其他配置的运行）
- [ ] 头部显示当前启动配置的 端口 / PID / 运行时长；二级 tab 上也带端口
- [ ] 切换二级 tab 时日志区切换、过滤条件保留
- [ ] 键盘 `←/→` 在输入框聚焦时不抢焦点
