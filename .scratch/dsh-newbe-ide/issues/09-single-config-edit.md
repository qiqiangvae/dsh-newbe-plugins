# 09: 启动配置一次只编辑一条

**What to build:** `⚙ 配置` 展开的配置块过去把项目下**所有**启动配置的表单堆在一起：一屏里四五个「名称 / 启动命令 / 工作目录 / 环境变量」，每条都带自己的「保存」「删除」。配置一多就看不出在改哪条，点错「保存」还会把别条的草稿一起写下去。改成只出现**当前在左列选中的那一条**：改完就在同一条表单里保存或删除。

**Blocked by:** 04（一个项目多条启动配置）、08（左列配置列表）

**Status:** ready-for-human（已实现并在真机验证）

- [x] 配置块只渲染选中那条的表单：名称 / 启动命令 / 工作目录 / 环境变量
- [x] 表单标题写明在改哪条（`正在编辑：<名称>`），避免"这是哪个配置"的困惑
- [x] 保存 / 删除都作用于这一条；删除后自动落到剩下的第一条（`removeConfig` 原有行为）
- [x] 切换左列选中项时表单跟着换（草稿仍按 configId 分开存，未保存的改动来回切不丢）
- [x] 项目没有任何配置时，配置块照样能打开：显示提示 + `添加项目` / `从 IDEA 导入` 仍在，不再是一条死胡同

- 一次只提交一条的状态意味着并发写窗口没变（面板仍是唯一写者，整份状态提交）。
- 真机验证（Playwright，zagent 项目）：配置块里 `.ide-form` 数量 = 1；`正在编辑：` 与表单 `名称` 跟随左列选中项；用「＋ 启动配置」加一条 → 表单自动切到新条 → 点表单里的「删除」→ 该条消失，磁盘状态与操作前逐 id 一致（自己加的临时配置已清掉，用户原有的配置未动）。
