# 06: 规模化：tab 滑动与隐藏 + 总览

**What to build:** 项目多到 tab 条放不下时仍然好用：tab 条可横向滑动、`»` 里有全部 tab、`只看运行中` 一键隐藏没在跑的；可配置的「总览」tab 打开后按项目分卡，卡内逐条列出启动配置与最后一行日志，点一下跳过去。

**Blocked by:** 04 (一个项目多条启动配置：两层 tab)

**Status:** ready-for-human（实现完成，滑动与总览需真机看一眼）

- [x] tab 条横向滑动：滚轮 / 触控板横滑、按住拖动都能滚动；选中 tab 自动滚入视野
- [x] `»` 菜单列出全部项目（含被滚出视野的与已收起的），点击可跳转；已收起的会同时恢复
- [x] `×` **收起**项目 tab：配置全部保留（`hidden` 标记），从 `»` 菜单恢复。**不采用"从 ＋ 添加项目 重新加入"**——那会丢掉该项目下的启动配置，见 Comments
- [x] `只看运行中` 开关隐藏所有未运行的项目的 tab（被隐藏的仍在 `»` 里）
- [x] `总览` 是配置项，默认关闭；打开后按项目分卡、卡内逐条列启动配置（状态点、端口、时长、最后一行日志、各自启停按钮）
- [x] 总览里点击配置名跳到它的二级 tab（开总览前会先关掉总览）
- [x] 总览开关状态落在 `showOverview`，重启 DSH 后保持（往返由存储测试覆盖）

## Comments

**实现记录（2026-09-12）**

- **`×` 是"收起"而不是"移除"**：票里原写"关闭后仍能在 ＋ 添加项目 里重新加入"，但配置是存在项目条目里的，移除条目等于删掉该项目的全部启动配置。改成 `hidden` 标记：配置原样保留，`»` 菜单里显示"已收起"并可一键恢复。
- **`hidden` 带默认值**（`z.boolean().default(false)`）：老文件没有这个字段，若无默认值会被判为损坏而回退成空配置——那等于把用户已有的配置全丢掉。补了一条"老文件仍能读回且配置不丢"的测试。
- **最后一行日志在宿主侧维护**（`lastLine`）：总览要显示每条配置的最后一行，而客户端只有当前配置的日志；宿主有全部缓冲，逐行维护成本可忽略。
- **滚轮必须用原生监听**：React 的 `onWheel` 是被动监听，`preventDefault()` 不生效，横滑会连带把页面滚走。
- **`runAction` 支持显式目标**：总览里可以直接启停别的项目的配置，不必先切过去。

**合并评审处理（2026-09-12，本轮覆盖票 04–06）**

Spec 轴 6 条（全部为真缺陷）：

| 发现 | 处理 |
| --- | --- |
| **横向滑动是死代码**：监听挂在 `useEffect(…, [])` 里读 `tabRowRef.current`，而首帧 `config` 还是 null、tab 行不在 DOM 里，ref 为 null 且永不重跑 | 依赖改成"面板是否已渲染"（`panelReady`），并写明为什么不能用 `[]` |
| **没选配置时整个轮询早退**：刚加上还没建配置的项目会让总览卡片与所有状态点冻结（票 04 注释里"每 800ms 重绘一次"在那时是假的） | `runs()` 无条件轮询；只有"读当前配置日志"这一步才要求有选中项 |
| 从总览启动**当前正在看的那条**配置时不清日志缓冲，新输出接在旧日志后面 | 判定改成"启动的是当前查看的那条"（含显式指定当前项） |
| **收起选中的项目后 body 还渲染它**：tab 行里没有选中项，`只看运行中` 下 `»` 也救不回来 | 选中项被过滤掉（收起 / 只看运行中）时自动切回第一个仍可见的项目 |
| **删掉在跑的配置会留下孤儿进程**（端口占到 DSH 退出） | 删除配置/项目前先 `stop` 掉它名下的进程 |
| `.idea/workspace.xml` 缺失时静默跳过，只说"扫过 0 个文件" | 一个文件都没扫到时给出可读原因 |
| 生成的命令漏了 `-o`（与规格和本项目的离线跑法不一致） | 补 `-o` |
