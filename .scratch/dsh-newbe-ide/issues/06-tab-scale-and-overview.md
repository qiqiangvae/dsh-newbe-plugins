# 06: 规模化：tab 滑动与隐藏 + 总览

**What to build:** 项目多到 tab 条放不下时仍然好用：tab 条可横向滑动、`»` 里有全部 tab、`只看运行中` 一键隐藏没在跑的；可配置的「总览」tab 打开后按项目分卡，卡内逐条列出启动配置与最后一行日志，点一下跳过去。

**Blocked by:** 04 (一个项目多条启动配置：两层 tab)

**Status:** ready-for-agent

- [ ] tab 条横向滑动：滚轮 / 触控板横滑、按住拖动都能滚动；选中 tab 自动滚入视野
- [ ] 溢出时 `»` 菜单列出全部 tab（包括被关闭视野外的），点击可跳转
- [ ] `×` 关闭 tab；被关闭的项目仍在 `＋ 添加项目` 里可重新加入
- [ ] `只看运行中` 开关隐藏所有未运行的项目的 tab（被隐藏的仍在 `»` 里）
- [ ] `总览` 是配置项，默认关闭；打开后按项目分卡、卡内逐条列启动配置（状态、时长、最后一行日志、各自按钮）
- [ ] 总览里点击某条启动配置跳到它的二级 tab
- [ ] 总览开关状态重启 DSH 后保持
