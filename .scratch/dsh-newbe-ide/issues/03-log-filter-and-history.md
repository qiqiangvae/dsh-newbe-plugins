# 03: 日志能用：过滤 + 落盘历史

**What to build:** 日志区能按关键字（含正则）、按 level（ERROR/WARN/INFO/DEBUG/OTHER）、按"仅看匹配"过滤，且过滤状态下仍然自动跟随；日志同时落盘，DSH 重启后还能翻到上一次跑的输出。

**Blocked by:** 02 (一条启动配置能一键启停，日志实时滚出来)

**Status:** ready-for-agent

- [ ] 关键字过滤即时生效；「正则」开关切换后按正则解释，非法正则退回字面匹配且不报错
- [ ] `仅看匹配` / `全部高亮` 两种模式可切换
- [ ] level 徽章多选，任一关闭后对应行立即消失
- [ ] 过滤开启时新到达的匹配行仍自动跟随；不匹配的行不打断跟随
- [ ] 单条启动配置的日志达到环形上限后从头部丢弃，滚动不卡（数千行量级）
- [ ] 日志同时追加落盘到 `$DSH_HOME/storages/dsh-newbe-ide/` 下；DSH 重启后能读回上一次的输出
- [ ] 面板显示"已缓存 N 行 / 显示 M 行"，并提示输出过快导致的截断
