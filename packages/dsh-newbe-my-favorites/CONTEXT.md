# My Favorites Plugin

此插件为 DSH Desktop 提供会话与网址的快捷收藏能力。

## Language

**会话收藏**:
指向当前 DSH 实例内可重新打开的会话标识的本机快捷条目。
_Avoid_: 会话备份、会话副本

**网址收藏**:
由名称、受支持 URL 与显示徽标组成的本机外部链接条目。
_Avoid_: 浏览器书签、网页存档

**Preset**:
会话标题栏中用于展示当前预设/工作模式的控件；会话收藏图标紧邻其后。
_Avoid_: XX 模式、编码模式

**网址标签**:
常驻展示全部网址收藏的紧凑侧栏标签；可见内容按“网站 favicon → 自定义 icon → 名称”的顺序解析，favicon 不可用时继续回退。
_Avoid_: 网址列表项、浏览器书签

**会话收藏夹**:
默认收起的内联侧栏容器；点击 `★ 会话 (N)` 展开会话收藏，切换会话后自动收起。
_Avoid_: 会话标签常驻列表

**收藏入口**:
位于左侧侧栏“新会话”按钮正下方的收藏区域，包含网址标签和会话收藏夹。
_Avoid_: 侧栏底部收藏入口
