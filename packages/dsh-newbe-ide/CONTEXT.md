# IDE Plugin

此插件为 DSH Web 提供会话视图 tab「IDE」：按项目组织启动配置，一键启停，日志留在浏览器里。

## Language

**项目**:
一个 DSH 工作区（`workspaceRegistry` 里的实体，有路径与标题），在面板里占一个一级 tab。
_Avoid_: 工程、repo、workspace、仓库

**启动配置**:
一条具名的可启动条目：名称 + 启动命令 + 工作目录 + 环境变量。一个项目下可以有多条，各自独立进程与日志。
_Avoid_: 命令、任务、run item、运行项

**启动命令**:
启动配置里那行 shell 字符串，在宿主侧由 `shell` 服务执行。
_Avoid_: 脚本、cmd

**面板**:
会话视图里的 tab「IDE」（`conversation.view`，对话 0 / 轨迹 10 / 上下文 20 / IDE 30）。它同时是运行控制台和配置入口。
_Avoid_: 全局面板、侧栏入口、窗口

**运行态**:
一条启动配置的当前进程状态：未启动 / 运行中 / 已停止 / 已退出（码 N）/ 启动失败。
_Avoid_: 状态机、健康状态

**日志**:
该启动配置进程的 stdout + stderr 合并流；按行切分、剥 ANSI、收敛 `\r` 覆写，密钥值掩码。
_Avoid_: 输出、terminal、控制台

**收起**:
把一个项目从面板的 tab 行移开，但**保留它的全部启动配置**（`hidden` 标记）；从 `»` 菜单恢复。
_Avoid_: 关闭、删除、移除

**总览**:
面板首位的常驻 tab：按项目分卡，卡内逐条列启动配置的状态、端口、时长与最后一行日志。
点卡里的配置名会跳到该项目（收起或被「只看运行中」滤掉的项目也会一并放出来）。
_Avoid_: 仪表盘、dashbord、概览页
