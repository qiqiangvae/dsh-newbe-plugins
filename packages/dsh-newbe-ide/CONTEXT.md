# IDE Plugin

此插件为 DSH Web 提供会话视图 tab「IDE」：按项目组织启动配置，一键启停，日志留在浏览器里。

## Language

**项目配置**:
一条「路径 + 标题 + 它名下的启动配置」的记录，在面板里占一个一级 tab。
路径**不限于 DSH 工作区**（任意目录都能建），而且**同一路径可以有多条**（各自独立的启动配置）。
记录自带一个与任何工作区无关的 `id`；DSH 工作区只是新增卡片里的一份**快捷列表**，不是身份来源。
_Avoid_: 项目、工作区、工程、repo、workspace、仓库

**启动配置**:
一条具名的可启动条目：名称 + 启动命令 + 工作目录 + 环境变量。一条项目配置下可以有多条，各自独立进程与日志。
_Avoid_: 命令、任务、run item、运行项

**启动命令**:
启动配置里那行 shell 字符串，在宿主侧由 `shell` 服务执行。
_Avoid_: 脚本、cmd

**面板**:
会话视图里的 tab「IDE」（`conversation.view`，对话 0 / 轨迹 10 / 上下文 20 / IDE 30）。它同时是运行控制台和配置入口。
_Avoid_: 全局面板、侧栏入口、窗口

**运行态**:
一条启动配置的当前进程状态：未启动 / 运行中 / 已停止 / 已退出（码 N）/ 启动失败。
_Avoid_: 状态机、健康状态

**日志**:
该启动配置进程的 stdout + stderr 合并流；按行切分、剥 ANSI、收敛 `\r` 覆写，密钥值掩码。
_Avoid_: 输出、terminal、控制台

**常驻窗口**:
浏览器里为该配置保留的日志行数上限。超出上限的旧行不再占内存，但**仍在磁盘上**，可以分页读回来。
_Avoid_: 缓存、buffer、滚动窗口

**分页**:
往回滚超过常驻窗口时，按字节窗口从磁盘上的日志文件往回读更早的内容。读到轮转边界就是到底了——那时必须明说"更早的已被丢弃"，不许静默截断。
_Avoid_: 加载更多、懒加载、无限滚动

**行号**:
面板给每行编的连续序号：跨分页稳定，**清空视图后继续往后走、不倒退**。
它是面板自己的编号——**不是**磁盘文件里的行号（文件只留尾部两代，对不上），也不保证等于"该次运行的第几行"（面板可能中途才接上）。
_Avoid_: 下标、offset、索引

**清空**:
把面板当前的日志**视图**清掉：宿主缓冲与磁盘上的日志文件都不动，所以"上次为什么挂"仍在，刷新页面还能重新读到宿主缓冲里的内容。
**不是删除日志**——删文件是另一件事，需要单独的按钮与确认。
_Avoid_: 删除日志、清理磁盘、清屏（清屏是它的近义词，但"清空"在面板里就指这个）

**收起**:
把一条项目配置从面板的 tab 行移开，但**保留它的全部启动配置**（`hidden` 标记）；从 `»` 菜单恢复。
_Avoid_: 关闭、删除、移除

**总览**:
面板首位的常驻 tab：按项目配置分卡，卡内逐条列启动配置的状态、端口、时长与最后一行日志；
最后一张是**新增卡片**（任意路径 + DSH 工作区快捷列表）。点卡里的配置名会跳到那条项目配置
（收起或被「只看运行中」滤掉的也会一并放出来）；0 配置的卡片用「打开」进。
_Avoid_: 仪表盘、dashbord、概览页
